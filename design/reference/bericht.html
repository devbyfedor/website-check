Was passiert

Ihre Startseite lädt zwei Dateien direkt von Google-Servern, 0,3 Sekunden nach dem Aufruf. Google erhält dabei die IP-Adresse jedes Besuchers, bevor dieser zustimmen kann.

Warum das wichtig ist

Das Landgericht München I hat 2022 einem Besucher dafür Schadensersatz zugesprochen. Die Lösung ist einfach und kostet nichts.

Montageanleitung

  1. Finden Sie heraus, ob Ihr Theme oder ein Plugin die Schrift einbindet. Oft steht es in den Theme-Einstellungen unter „Typografie“.
  2. Binden Sie die Schrift lokal ein, zum Beispiel mit einem Plugin für lokale Google Fonts. Die Dateien liegen danach auf Ihrem eigenen Server.
  3. Starten Sie eine neue Prüfung. Die Anfrage an Google sollte verschwunden sein.
  1. Shopify liefert die Schriften Ihres Themes von eigenen Servern. Google Fonts kommen meist aus einer App oder aus eingefügtem Code.
  2. Suchen Sie unter Onlineshop › Themes › Code bearbeiten nach fonts.googleapis.com und entfernen Sie die Einbindung.
  3. Wählen Sie die Schrift in den Theme-Einstellungen aus der Shopify-Schriftbibliothek und starten Sie eine neue Prüfung.
  1. Wix stellt seine Schriften selbst bereit. Google Fonts laden meist über ein eingebettetes HTML-Element oder eine App.
  2. Entfernen Sie den eingebetteten Code oder die App, die die Schrift lädt.
  3. Laden Sie die gewünschte Schrift als eigene Datei hoch und starten Sie eine neue Prüfung.
  1. Prüfen Sie, ob in den Einstellungen eigener Code im Kopfbereich der Seite eingetragen ist.
  2. Entfernen Sie jede Zeile mit fonts.googleapis.com.
  3. Wählen Sie eine Schrift aus den Design-Einstellungen und starten Sie eine neue Prüfung.
  1. In Shopware 6 bindet das Theme die Schriften ein.
  2. Legen Sie die Schriftdateien in den Ordner Ihres Themes und binden Sie sie per @font-face ein, nicht über fonts.googleapis.com.
  3. Kompilieren Sie das Theme neu, leeren Sie den Cache und starten Sie eine neue Prüfung.
